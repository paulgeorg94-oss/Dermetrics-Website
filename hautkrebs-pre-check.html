Risiko-Score

 Punkte
Kein diagnostisches Werkzeug. Dieser Pre-Check ist ein statistisches Orientierungsinstrument. Die genannten Raten stammen aus epidemiologischen Studien zu Risikogruppen und sagen nichts über eine tatsächliche Erkrankung im Einzelfall aus: Ein niedriges Ergebnis schliesst schwarzen Hautkrebs nicht aus, ein hohes bedeutet keine Diagnose. Nur eine ärztliche Untersuchung kann Hautkrebs feststellen oder ausschliessen.

Ergebnis als PDF erhalten

Speichern Sie Ihr Ergebnis als anonymes PDF — ohne Namen oder sonstige personenbezogene Angaben. Der Button öffnet den Druckdialog Ihres Browsers; wählen Sie dort als Ziel „Als PDF speichern". Optional können Sie das gespeicherte PDF anschliessend über Ihr eigenes E-Mail-Programm an sich selbst senden.

Hinweis zur Übermittlung: Das PDF wird ausschliesslich lokal auf Ihrem Gerät erstellt und enthält keine personenbezogenen Angaben — es wird nicht an einen Server übertragen oder dort gespeichert. Der optionale Versand per E-Mail erfolgt über Ihr eigenes E-Mail-Programm als reguläre, unverschlüsselte Übertragung — vergleichbar mit einer gewöhnlichen E-Mail. Für hochsensible Gesundheitsangaben ist unverschlüsselte E-Mail nicht geeignet; senden Sie das PDF entsprechend nicht an Dritte weiter.
